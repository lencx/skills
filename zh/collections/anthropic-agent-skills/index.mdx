<div class="curated-story">
<div class="curated-story__lede">
<p class="curated-story__thesis">它不是一套软件交付制度。它真正有价值的地方，是用一手文件展示 Skill 如何打包、渐进加载，以及如何与 baseline 对照评估。</p>
<p>每项 Skill 都是可独立加载的目录：名称与 description 常驻用于发现，触发后才加载 SKILL.md，脚本、references 与 assets 按需使用。仓库中的 skill-creator 还会让真实提示分别运行启用 Skill 与 baseline，评估断言和输出质量，再根据人工反馈迭代。</p>
</div>
<section class="curated-story__section curated-story__signature" aria-labelledby="signature-model">
<header class="curated-story__section-heading">
<h2 id="signature-model">什么内容会在何时进入上下文</h2>
<p>Skill 的目录结构本质上是一份上下文预算契约：发现成本要低，触发后才加载主流程，较重的知识和工具只在任务真正需要时出现。</p>
</header>
<div class="curated-signature curated-signature--layers" data-story-kind="layers">
<article class="curated-signature__item" style="--story-index:1"><span class="curated-signature__meta">始终可见</span><h3>name + description</h3><p>发现元数据同时告诉模型这个 Skill 做什么，以及何时应该选择它。</p></article><article class="curated-signature__item" style="--story-index:2"><span class="curated-signature__meta">触发之后</span><h3>SKILL.md</h3><p>只有触发条件匹配后，主决策流程才进入上下文。</p></article><article class="curated-signature__item" style="--story-index:3"><span class="curated-signature__meta">按需使用</span><h3>scripts / references / assets</h3><p>确定性操作、可选知识和输出素材保持在主提示之外，直到被引用或执行。</p></article>
</div>

<section class="curated-story__section" aria-labelledby="project-mechanisms">
<h2 id="project-mechanisms">这个仓库真正教会你的 Skill 设计</h2>
<div class="curated-story__mechanisms">
<article><h3>三级上下文加载</h3><p>发现元数据始终可见，触发后才加载 SKILL.md，附带资源只在真正需要时进入上下文或执行。</p></article><article><h3>行为与 Baseline 对照评估</h3><p>skill-creator 让真实提示分别启用与不启用 Skill，评估断言、输出、成本和耗时，并提供人工 Review。</p></article><article><h3>从极简到生产型示例</h3><p>极简模板与 Claude 实际使用、包含脚本和素材的文档工作流并列，也明确揭示不同许可边界。</p></article>
</div>
</section>
<section class="curated-story__section" aria-labelledby="project-practice">
<h2 id="project-practice">先评估行为，再润色文字</h2>
<ol class="curated-story__practice">
<li><p>从模板开始，description 要同时说明 Skill 做什么，以及什么情况下应当触发。</p></li><li><p>把主流程留在 SKILL.md，将重复操作、按需知识和输出素材分别放入 scripts、references 与 assets。</p></li><li><p>把触发失败与输出失败分开诊断：description 使用触发 eval，正文使用任务断言和人工 Review。</p></li>
</ol>
</section>
